Barbarian Soldier Texture Pack

Recommended Unity setup:
- BaseColor: sRGB ON
- Normal: Texture Type = Normal map
- Roughness / Metallic / AO / Height: sRGB OFF
- Suggested shader: URP/Lit or Standard Lit
- Use Metallic map in Metallic slot.
- Use Roughness as Smoothness by inverting it if your shader expects Smoothness.
