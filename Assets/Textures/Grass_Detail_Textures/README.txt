Unity Terrain Grass Detail Texture Pack

These PNGs are transparent grass blade textures for:
Terrain > Paint Details > Add Grass Texture > Detail Texture

Files:
- Grass_Short_Green.png
- Grass_Tall_Green.png
- Grass_Dry_Yellow.png
- Grass_Weed_Mixed.png
- Preview.png

Recommended Unity settings:
1. Select the PNG in Project window.
2. Texture Type: Default
3. Alpha Source: Input Texture Alpha
4. Alpha Is Transparency: ON
5. Wrap Mode: Clamp
6. Filter Mode: Bilinear
7. In Terrain Paint Details, use these as Detail Texture.

Suggested Detail settings:
- Min Width: 0.15
- Max Width: 0.45
- Min Height: 0.4
- Max Height: 1.2
- Noise Spread: 0.6 - 1.5
- Detail Density: 0.4 - 0.8
- Billboard: ON

Note:
Do not use Roughness/Normal/Height maps here. Terrain Grass Detail Texture mainly uses RGB color + Alpha transparency.
