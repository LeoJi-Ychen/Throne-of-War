Grass Texture Pack for Unity Terrain

Files:
- Grass_Albedo.png: Base color / Diffuse
- Grass_Normal.png: Normal map
- Grass_Roughness.png: Roughness map
- Grass_Height.png: Height map
- Grass_AO.png: Ambient Occlusion
- Grass_Metallic.png: Metallic map, should remain black
- Preview.png: texture preview

Unity Terrain usage:
1. Select Terrain.
2. Paint Terrain > Paint Texture.
3. Edit Terrain Layers > Create Layer.
4. Assign Grass_Albedo.png to Diffuse.
5. Assign Grass_Normal.png to Normal Map.
6. Suggested tile size: 8 x 8 or 12 x 12.
7. For URP/HDRP materials, use Roughness/Height/AO if your terrain shader supports them.
